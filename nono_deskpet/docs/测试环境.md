# NONO 桌宠 · Wine 测试环境

## 一次性 vs 持久：结论

| 东西 | 位置 | 会不会丢 |
|---|---|---|
| 字体文件 | `tools/winefonts/*.ttc` | 不丢（持久工作目录） |
| `bcryptprimitives.dll` 桩 | `tools/winefonts/bcryptprimitives.dll` | 不丢 |
| 初始化脚本 | `tools/wine_env.sh` | 不丢 |
| Wine prefix（/tmp/nono-wine） | `/tmp` | **会丢**（重启/清理 /tmp） |

所以：**字体本身是持久的，prefix 不是**。prefix 丢了跑一次脚本就能恢复，不用手工再折腾。

## 每次测试前跑一句

```sh
sh /app/working/workspaces/a2ZDuB/tools/wine_env.sh
```

脚本幂等，重复执行不会重复拷贝（已存在就跳过），做的事：

1. prefix 不存在 → `wineboot -i` 初始化
2. 拷中文字体到 `drive_c/windows/Fonts`
3. 拷 `bcryptprimitives.dll` 桩到 `drive_c/windows/system32`（缺它 Go 程序直接 panic）
4. 写注册表字体替换：`Microsoft YaHei` / `SimSun` / `MS Shell Dlg` / `宋体` / `微软雅黑` → `WenQuanYi Micro Hei`

## 为什么需要字体

程序用 `CreateFontW("Microsoft YaHei")`。Wine 的 prefix 默认是空的 `Fonts` 目录，找不到字形时 Win32 回退到空字体，中文全部画成方块。

**真机 Windows 自带微软雅黑，不会出现这个问题。** 只有精简系统 / 英文系统 / Wine 才需要手动补。
